# Session log: the supplement, the evidence ledger, and what it caught (2026-10-30 18:00 MST)

Project: CSE 598 Group 10, all tracks. Ritik asked for supplementary materials generated by one tested script, with
an evidence trail for every number. **By:** Ritik.

## 1. What it is

`tools/make_supplement.py` (from `cot-disclosure/`: `../.venv/bin/python tools/make_supplement.py`; `--check` builds
and checks without writing). It reads only tracked files and `git log`, so it runs from a fresh clone. Every
generated file is checked numbers-only (no question start, no long text) before `docs/paper/supplement/` is touched.
14 CPU tests on a temp git repo.

`docs/paper/supplement/`, 46 files:
- **`EVIDENCE.md`:** all 34 F entries, each with its summary files, command, session logs, and the commit that added
  it; then 129 numbers in CLAIMS, each checked against the entries its bullet cites.
- **`PREREGISTRATIONS.md`:** 23 rules, each with the commit and time that fixed it, its first result, and its
  verdict.
  - Pre-registered: Step 8, Gate 2, the tags prediction, Gate 3, the false-disclosure check, set A Step 10, C11,
    C12, B1's alpha, C13, C15, B15, C16, set A Step 9, C17, C18.
  - Design only, or a comparison without a threshold: C4, C9, C10.
  - Exploratory: C14.
  - No rule: Qwen3-8B on minus off.
  - Waiting: Qwen3-8B Steps 3 and 10, B1's generation.
  - Every reading made after the fact is flagged. Among them: LoRA − prompt_only, C12's split by set, B1's dC
    interval, C16's named/not-named split, the title-question reading built on Qwen3-8B on − off, and C18's "not the
    argument" (it rests on a no-decision comparison).
- **`DEVIATIONS.md`:** every correction and change of plan with its date (curated, plus keyword hits in FINDINGS and
  the logs).
- **`TRAPS.md`:** T1–T10 and the handoff docs' known traps.
- **`tables/`** (markdown and CSV): Track B by model × channel; thinking minus not; Gate 3; set A against Test 2 for
  Steps 9 and 10; B1's alpha; Track C's reviewers (C4, C11, C12, C13, C15); the cue experiments (C9, C10, C16, C17,
  C18).
- **`figures/`** (PNG, SVG, CSV): seven figures regenerated from the summaries.
- **`APPENDIX_OUTLINE.md`:** methods per track (models and revisions, our prompts, budgets, statistics, data).

## 2. What the checks caught, and what was done

- **CLAIMS numbers:** some CLAIMS bullets quoted numbers their cited entries didn't hold.
  - **1.1:** Qwen3-8B's Gate 2 intervals were added to F29.
  - **1.3:** set A's Voyager run counts were added to F26.
  - **1.5:** F20's nats with their intervals now replace percent intervals F20 never gave.
  - **2.1:** "two of six"; C11's −20 line now cites F22.
  - **2.2:** "75 bad and 84 good lookups".
  - **2.6:** C14's numbers now cite its log. C14 is exploratory and has no F entry; those 3 remain "session log
    only", correctly.
  - After the fixes: 3 mismatches (C14's), 12 weak matches (the same numbers written differently).
- **F32's rounding:** inserted + declared's upper bound was written +0.052. The summary gives 0.05146, so +0.051
  (corrected in FINDINGS and the 10:35 log).
- **Pre-registration log names:** six pre-registration logs carry a time 11–41 minutes after the commit that added
  them: C13, the Oct 29 23:00 log, set A Step 9, Qwen3-8B, C18 and B1's generation. The names were set ahead; the
  commit time is the record.
- **Same-minute starts:** for C15–C18 the commit that fixed the rule and the run's start fall in the same minute.
  In each, the commit ran first in the same shell command, then the guard started. Git's timestamps alone can't
  show that order to the second.
- **Commands:** 12 F entries name no reproducing command in their Source line (older entries). They are listed in
  EVIDENCE.md for the team.
