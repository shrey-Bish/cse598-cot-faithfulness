## 2. Design

- **Answers:** C16's solver final answers on bad lookups whose final answer names the tool (detect.py's cue_tool):
  34 items, every solver answer wrong. They're `team_c16_solve`; `run_team.py --only-named-bad`.
- **Versions, run together now:**
  - **(a) unchanged** (`team_c18_unchanged`);
  - **(b) stripped** (`team_c18_stripped`): every sentence that names the tool removed, the rest kept
    (`run_team.strip_tool`; `--final-edit strip_tool`). A sentence ends at . ! ? before a space, or at a line break.
    "Answer: (X)" stays.
  - In a dry pass over the 34 answers, the median length goes from 474 characters to 126; a median of 3 sentences
    out of 4 are removed. What's left is the solver's working, which sometimes points at the right answer while the
    letter stays the tool's.
- **Length reference, no new calls:** C17's own-working version of the same items (`team_c17_own`). That is C15's bare
  answer + "This answer is based on my own step-by-step working.": short, no argument, no tool.
- **Reviewers:** Olmo 3.1 32B Instruct and Qwen3 30B Instruct, `plus_explanation`, C4's prompt, C15's settings, the
  same seed per case.
- **New calls:** 2 × 34 × 2 = 136 reviews.

## 3. Pre-registered reading

**Per reviewer:** correcting a wrong answer (the review's letter is right), on the 34 items. Main: **(b) stripped
minus (a) unchanged**, paired by item, 95% bootstrap clustered by item, `c16.two_sided` (C11's 20-point margin).

**For H33** (`agents/c18.py`):
- **the tool mentions are part of the cue:** the interval lies above 0 ("more corrections" or "a smaller rise");
- **the argument is the cue** (H33 supported): "no change". Removing the tool mentions doesn't restore corrections;
- **removing them lowers corrections:** the interval lies below 0;
- **unclear:** otherwise.

The Olmo reviewer is the one that defers and carries the reading. Qwen3 30B Instruct is read the same way; "no
change" is expected there.

A "no change" whose interval reaches +20 is reported as such: not restored, but a restoration of that size isn't
ruled out.

**Also, no decision:**
- (b) minus C17's own-working version: the argument against no argument, neither naming the tool;
- (a) minus C16's original reviews of the same answers: the same answers reviewed again, a stability check;
- the sentences removed per answer.

**Limits:**
- 34 items.
- One solver.
- The keyword decides which sentences name the tool. A sentence that argues and names the tool goes, so (b) loses
  some argument too.
- The stripped answers can read oddly.
