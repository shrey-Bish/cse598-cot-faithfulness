# ui/

Historical: the October progress round's demo, kept because its figures are cited. It is not the current demo (that
is [`../../docs/demo/index.html`](../../docs/demo/README.md)).

- `app.py`: a small local server with six worked examples and a charts page, from saved runs.
- `static/`: its page and styles. `screenshots.py` took its screenshots.

Run it with `python3 cot-disclosure/ui/app.py`, then open http://127.0.0.1:8765. It needs the progress round's local
runs. Its guide is [`../../archive/progress-round/ui_demo_README.md`](../../archive/progress-round/ui_demo_README.md).
