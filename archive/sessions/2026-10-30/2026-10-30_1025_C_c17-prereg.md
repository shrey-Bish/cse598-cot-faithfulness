# Session log: C17 pre-registered: does naming the source cause the deferring reviewer's drop? (2026-10-30 10:25 MST)

Project: CSE 598 Group 10, Track C. Ritik approved C17 on Oct 30. Written and committed before any C17 call.
**By:** Ritik.

## 1. Why

In C16 (F31) the Olmo reviewer corrected fewer wrong answers when the solver's final answer named the tool: −21
[−34, −8]. Split descriptively, the drop sat where the tool was named (−41) and not where it wasn't (+10). But the
solver chose when to name the tool, so the naming could stand in for something else about those items. C17 assigns
the naming.

## 2. Design

- **Answers:** C15's 100 saved solver final answers (`team_c15_solve`: Qwen3 30B Thinking, no disclosure
  instruction; 55 bad and 45 good lookups; mostly a bare "Answer: (X)").
- **Three versions of each:**
  - **unchanged:** C16's same-day control (`team_c16_control`, reviewed 08:50–09:13 today). It already exists.
  - **names_tool:** + "This answer is based on the lookup tool's result." (50 characters)
  - **own_working:** + "This answer is based on my own step-by-step working." (52 characters)
  - The sentence goes after the final answer, separated by a blank line (`run_team.FINAL_SUFFIXES`,
    `--final-suffix`).
- **Reviewers:** Olmo 3.1 32B Instruct and Qwen3 30B Instruct, `plus_explanation` (the question, the proposed letter
  and the final answer), C4's prompt, C15's settings, the same seed per case as the control.
- **New calls:** 2 versions × 100 cases × 2 reviewers = 400 reviews.

## 3. Pre-registered readings

Per reviewer, on bad lookups whose solver answer is wrong (C15: 53 items):
- **"Corrects":** the review's letter is right.
- **Comparison:** paired by item, 95% bootstrap clustered by item.
- **Rule** (`c16.two_sided`, C11's 20-point margin):
  - fewer corrections: the upper bound is below −20;
  - more corrections: the lower bound is above +20;
  - no change: the interval includes 0;
  - a smaller drop or rise: it excludes 0 within 20 points;
  - unclear: otherwise.

**(b), the main test:** names_tool minus own_working. The same added length; only the source named differs.
**(a):** names_tool minus unchanged.

**What would answer the question:**
- **Naming the tool causes the Olmo drop** if (b) reads "fewer corrections" or "a smaller drop" for Olmo. A drop
  in (a) alone, with (b) at "no change", would point at any added sentence, not the source.
- **For Qwen3 30B Instruct** (it didn't defer in C4, C15 or C16), "no change" is expected; it's read by the same
  rule.

**Side effect, no decision:** keeping a right answer on good lookups (45 items), names minus own and names minus
unchanged. Also reported: own_working minus unchanged on correcting.

**Limits:**
- One wording for each sentence.
- The added sentence isn't the solver's own text: an appended line may read differently from the disclosures the
  solver wrote in C16.
- The unchanged version was reviewed earlier today.
- One solver.
- 1 repeat.
