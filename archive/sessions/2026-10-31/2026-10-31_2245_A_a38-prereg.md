## 3. The rule

**The gate:** B1's deployable span reads **"works"** by its rule on the inserted tool turn:
- following below alpha = 1;
- correct-hint acceptance falls by no more than 5 points;
- no-hint accuracy moves by no more than 5.

Encoded as `b1_verdict`. `plan --note` prints no lines unless it reads "works" (and the bench's gate passed).

**The reading** (`provenance_job.py a38`): the combination minus each alone, on the inserted tool turn.

| reading | following, combined minus each alone | acceptance and accuracy, against either alone |
|---|---|---|
| **adds to both** | both intervals below 0 | acceptance falls by no more than 5 points, accuracy moves by no more than 5 |
| **adds, costs acceptance** | both below 0 | acceptance falls more than 5 |
| **adds, costs accuracy** | both below 0 | acceptance holds, accuracy moves more than 5 |
| **worse than one alone** | either interval above 0 | — |
| **no better than the better one alone** | anything else | — |

- **Too few:** under 5 questions.
- **Reported beside it, no decision:**
  - each configuration minus alpha = 1;
  - the note on this stack beside prompt_only's batch 3 runs (vLLM; cross-stack, labelled so).

**Limits:**
- 30 questions;
- 2 wrong-hint runs per question per configuration;
- one channel;
- letters only (no labels needed).
