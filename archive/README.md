[`../README.md`](../README.md) first.

| Folder | What is in it |

| [`superseded/`](superseded/) | Earlier versions of the front page, the overview, the plan, the Track C guide, the to-do notes and two earlier demos (Nov 13 page, Nov 14 Hint Explainer) |
| [`demo_build/`](demo_build/) | The brief and the inventory used to build the current demo |
| [`drafts/`](drafts/README.md) | Plain rewrites of the Track B and Track C start pages, offered to their owners (not in force) |
| [`merged-docs/`](merged-docs/) | The originals of docs that were merged into others, unchanged |
| [`progress-round/`](progress-round/) | The October progress presentation: decks, figures, screenshots, and the guide to its demo |
| [`MOVES.md`](MOVES.md) | Every file moved: old path, new path, and why |

If a link to an old path is broken, look it up in `MOVES.md`.
