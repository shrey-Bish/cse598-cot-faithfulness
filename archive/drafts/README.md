**What changed.** Plain names for the experiments (from [`docs/GLOSSARY.md`](../GLOSSARY.md)), with the internal codes kept in
parentheses where a reader needs them to find a log or a finding; stale status text brought up to date. Every rule, command,
path, date and number is as in the original. How much was reworded differs by section: the top of each page (what is done,
what is left, how you work) is rewritten in plain sentences; the long reference sections (setup steps, paths, rules,
the repo map, git, Claude Code) keep their commands and lists verbatim, with plain names added.

**What was dropped.** Nothing silently: each draft ends with a "Left out as stale" list, each item with the reason.

**Not in force until the owner moves it.** Another track's path (`docs/trackB/`, `docs/trackC/`) changes only with its owner's
agreement (the root `CLAUDE.md`), and Arsha has an unmerged commit that edits her page. So neither original was touched. To
adopt a draft, the owner copies it over the original on their own branch and drops the "Draft, not in force" note at its top;
to change it, edit it first. A link that would only work from the owner's folder (for example `SOL_ARSHA.md`, `FINDINGS_B.md`,
`sessions/...`) is written as a path in backticks, not a link, so it stays right in either place.
